PART 1 - CSP: LABORATORY SCHEDULING

1. CSP REPRESENTATION

Variables:
A = assignment of Section A
B = assignment of Section B
C = assignment of Section C

Each assignment is written as (Time Slot, Lab).

Domains after applying the unary constraints:

A = {(1,L1), (2,L1), (3,L1)}

B = {(2,L1), (2,L2), (3,L1), (4,L2)}

C = {(1,L2), (4,L2)}

Unary constraints:
1. A can use only time slots 1, 2, 3.
2. B can use only time slots 2, 3, 4.
3. C can use only time slots 1, 3, 4.
4. L2 is not available in time slot 3.
5. A must use L1.
6. C cannot use L1.
7. If B is in time slot 4, B must use L2.

Binary constraints:
1. A and B cannot have the same time slot.
2. B and C cannot have the same time slot.
3. Two sections cannot use the same lab at the same time.
4. A and C cannot be scheduled in consecutive time slots.


2. BACKTRACKING SEARCH USING MRV, DEGREE HEURISTIC AND FORWARD CHECKING

Initial domains:

A = {(1,L1), (2,L1), (3,L1)}
B = {(2,L1), (2,L2), (3,L1), (4,L2)}
C = {(1,L2), (4,L2)}

MRV values:

A = 3
B = 4
C = 2

Therefore C is selected first.

Assignment 1:
C = (1,L2)

Forward checking:
A cannot be in time slot 2 because A and C cannot be consecutive.

New domains:

A = {(1,L1), (3,L1)}
B = {(2,L1), (2,L2), (3,L1), (4,L2)}
C = {(1,L2)}

No domain becomes empty.

MRV values:

A = 2
B = 4

Therefore A is selected.

Assignment 2:
A = (1,L1)

Forward checking:
B cannot use time slot 1, but B has no time slot 1 in its domain anyway.

New domains:

A = {(1,L1)}
B = {(2,L1), (2,L2), (3,L1), (4,L2)}
C = {(1,L2)}

No domain becomes empty.

MRV selects B.

Assignment 3:
B = (2,L1)

All variables are assigned.

Final check:
A = (1,L1)
B = (2,L1)
C = (1,L2)

A and B have different time slots.
B and C have different time slots.
A and C use different labs at time slot 1.
A and C are not consecutive because both are in time slot 1.

Therefore the assignment is valid.

Backtracking:
No backtracking is required for this search path.

Empty domains:
No domain becomes empty.

Constraint violations:
No constraint is violated on the selected path.

PART 2 - TSP USING GENETIC ALGORITHM

The problem asks for a Genetic Algorithm for the TSP.

Representation:
A chromosome is a permutation of the 20 city numbers. City 1 is the hub and the tour returns to city 1 at the end.

Fitness:
fitness = 1 / total distance

Genetic operators:
1. Roulette Wheel Selection
2. Order Crossover (OX)
3. Swap Mutation
4. Elitism

The city coordinates given in the question are used to calculate Euclidean distances.
